# Visual Evidence Research

Build the evidence layer before visual production.

## Method

1. Convert the thesis into small, falsifiable or supportable claims.
2. Search primary scholarly records and publisher pages. Academic evidence defaults to peer-reviewed work from the previous three calendar years.
3. Permit older sources only for current official standards or when documenting the origin of a framework; label the exception.
4. Verify title, authors, year, DOI/URL, publication type and peer-review status.
5. Assign each claim one boundary: `supported`, `interpretation`, `design-decision`, or `needs-validation`.
6. Record which source supports which claim. A source list without claim mapping does not pass.
7. Prefer systematic reviews or syntheses for broad claims and empirical studies for narrow outcome claims.

## Output

Return a claim–evidence matrix ready for the visual manifest, unresolved gaps, and wording changes required to avoid overclaiming.

Reject invented citations, citation laundering, unsupported cost/speed/effectiveness promises, and any claim that an xAPI event automatically proves learning.
