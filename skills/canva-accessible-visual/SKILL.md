# Canva Accessible Visual

Create the specification before editing Canva.

## Procedure

1. Read the visual manifest, design tokens, Canva components and accessibility rules.
2. Select the smallest layout family that makes the relationship clear.
3. Fit information by removing duplication or switching to a carousel/companion; never solve density by shrinking below the minimum.
4. Specify canvas size, grid, hierarchy, exact visible copy, icon labels, relationships, reading order, alt text, long-description destination and companion CTA.
5. Create or update the editable Canva design using the Brand Kit.
6. Apply headings, alt text and reading order. Run Canva's accessibility checker.
7. Export PNG and PDF Digital. Verify the PDF outside Canva before marking accessible.

## Brand and link rules

- The latest approved infographic controls palette and visual identity.
- Preserve low-contrast brand colors for decorative use only.
- Pair icons and color with text.
- Commit only public view/template links, never private edit URLs.
- Show a short public URL beside every QR code.

Record any connector or Canva limitation in the manifest rather than hiding it.
