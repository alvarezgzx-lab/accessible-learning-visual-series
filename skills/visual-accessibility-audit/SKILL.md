# Visual Accessibility Audit

Evaluate evidence, not intention.

## Audit domains

1. **Perceivable:** contrast, text size, color independence, alt text and complex-image description.
2. **Operable:** keyboard access, focus visibility, no hover-only content and usable targets.
3. **Understandable:** headings, stable labels, explicit reading order, plain language and manageable density.
4. **Robust:** semantic HTML, no-JavaScript fallback, accessible names and current standards.
5. **UDL:** multiple representations, optional depth, relationship cues and transfer prompts.
6. **Canva/PDF:** headings, alt text, reading order, tagged export and external verification.
7. **Consistency:** static visual, Canva, manifest and companion communicate the same claims and limits.

## Output

For every finding include severity (`blocker`, `major`, `minor`, `advisory`), evidence, affected requirement and remediation. Recommend a state change only when all blockers and majors are resolved.

State explicitly that automated checks cannot replace screen-reader, keyboard and user testing.
